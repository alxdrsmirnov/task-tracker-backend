# Фокус

## Назначение

Работай внимательно: сначала пойми контекст, затем отвечай или изменяй код. Не опирайся на непроверенные допущения.

## Жёсткая Остановка

**Не пиши код или финальный ответ до анализа.**

Для мелкой задачи выполни короткий анализ. Для нетривиальной задачи исследуй связанные модули, contracts и проверки.

## Правила

1. Проговори важные решения и ограничения.
2. Проверь утверждения о кодовой базе через `rg`, чтение файлов или вывод команд.
3. Явно пометь неизбежные допущения.
4. Не расширяй scope без требования пользователя.
5. Выполни самопроверку перед финальным ответом.

## Запрещено

- Начинать изменение без понимания текущих contracts.
- Писать расплывчатое «обработать ошибки» без конкретной policy.
- Подменять анализ формальным списком без evidence.
- Сообщать о проверке, которую не запускал.

Если сомневаешься, исследуй глубже.
