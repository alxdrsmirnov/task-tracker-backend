# Git-Пуш

## Рабочий Процесс

1. Проверь текущую ветку, upstream, working tree и URL `origin`.
2. Убедись, что пользователь явно попросил выполнить push.
3. Если у ветки нет upstream, выполни `git push -u origin {branch}`.
4. Если upstream существует, выполни обычный `git push` текущей ветки.
5. Покажи remote branch и ссылку на ветку.

## Правила

1. Не считай упоминание этой команды разрешением на push без явной просьбы пользователя.
2. Не создавай коммиты; используй для этого отдельную команду.
3. Не создавай MR/PR.
4. Если локальных коммитов для push нет, объясни и остановись.
5. Если push отклонён, покажи ошибку Git и остановись.

## Формат Ответа

```text
✓ Push: origin/{branch}

Ветка: {url}
```

## Ссылка На Ветку

Собери URL из `git remote get-url origin`:

- GitLab: `{base}/-/tree/{branch}`, где `base` — URL репозитория без `.git`.
- GitHub: `{base}/tree/{branch}`.
